# Build artifacts

These files are preserved from the local project for inspection and convenient download. They are not a substitute for a clean rebuild.

- `esp32_uvc_ap_stream.bin`: locally produced ESP32-S3 application binary.
- `windows/mainwindow.exe`: locally produced Qt executable; it expects the matching Qt/Python runtime and model layout.

The full packaged local snapshot, including duplicated runtime trees, is intentionally not published. Rebuildable source and the smallest useful inspection artifacts belong in the repository; workstation backups do not.
