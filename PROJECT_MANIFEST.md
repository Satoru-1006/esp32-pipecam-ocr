# Project manifest

This manifest separates project evidence from generated environment state. The original local directory remains untouched.

## Included in Git history

- ESP-IDF project files, `main.c`, font data, `sdkconfig*`, `dependencies.lock`, and `managed_components/`.
- Qt/C++ source, `.pro`, `.ui`, headers, Python bridge code, and preserved adapter sources.
- Local OCR model files and model archives used by the host project.
- Curated sample images, debug ROI images, captures, CSV/SQLite result artifacts, and UI screenshots.
- Research reports, schematics, original instructions, firmware binaries, Windows executable artifact, and the supplied field video.
- A static GitHub Pages presentation under `docs/`.

## Not published

The original `扫码枪.zip` backup is retained locally outside the public repository. Its central directory contains 103,416 entries and about 3.54 GB uncompressed data, including three duplicated Python/runtime trees. It is deliberately not published because it is a workstation snapshot rather than a maintainable project distribution.

## Excluded from normal Git history

- ESP-IDF `build/`, CMake/Ninja state, compiler objects, maps, logs, and absolute machine paths generated by the build.
- Qt Creator `.qtc_clangd/`, qmake Makefiles, `.qmake.stash`, object files, and Python bytecode caches.
- The duplicated embedded Python runtime trees `mainwindow/hunhe/`, `mainwindow/Lib/`, and `mainwindow/release/Lib/` as source-tree directories.
- The unrelated `_schematic_renders/` directory, which is a general document-render cache and contains material outside this PipeCam project.

These exclusions are not silent omissions: they are generated or duplicated environment material, documented here so the public repository stays inspectable and reproducible.
